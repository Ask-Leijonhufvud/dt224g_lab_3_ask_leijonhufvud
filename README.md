# DT224G - Laboration 3

Detta är/var ett skolprojekt som gick ut på att skapa en hemsida för en fiktiv naturdestination vid namnet _Norrgläntan_.

Bilder och wireframe tillhandahölls av lärarna.

Hemsidans layout ändras beroende på hur stort fönstret är.

Hemsidans färger ändras beroende på om man föredrar ljust eller mörkt läge.
